Hello World!

Welcome to UMI Dashboard, a prototypical energy simulation results viewer based on our Rhino-integrated Urban Modeling Interface [UMI]. UMI Dashboard is a web-powered service that allows quick, beautiful and interactive visualizations of simulation results stored in UMI files. Launch an example file with the MIT Model Data, or load your own project to get started.

Projects loaded from file are never uploaded or stored on a server or in a database. Files are simply accessed from your computer for the simulation.
